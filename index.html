Bred Minds

Six great minds, grown as small pattern-models from their own public-domain books, on one laptop. Then a hard test: a small local model writes new answers from each model alone, and a judge who never sees the models has to say whose pattern of thought each answer carries.

What these are. Models of thought-patterns grown from public texts. They are not the people, not resurrections and not conscious. A mind here is a card: twelve one-sentence maxims drawn from the author's own words, each checked against the passage it came from, plus two short samples of the author's voice. Nothing here claims to know what the author would really say.

Every claim below was written down and sealed before the code that measures it, then measured once. The failures are kept. Every number on this page is read from the committed records as it loads.

Start here

  1. Open a card (The cards). Pick a mind and read its twelve maxims. Open any maxim to see the passage of the book it came from, and why the gate kept it.
  2. Take the blind test (Blind test). You get an answer the local model wrote from one card, from a sham card, or from no card at all. Guess whose pattern it carries. Then see the truth, and what the judge said.
  3. Grow the trace model in your browser (Trace model). The page fetches the six books from this site (5.4 MB), checks each one's fingerprint, cuts the passages, fits the model and re-runs its test on passages it never saw. Then paste any text and see whose words it reads most like.
  4. Read the results (Results): the seven sealed claims, each held or failed, with its numbers.
  5. Meet the children (Breeding). Pick any of the 15 pairs. Read the child the local model wrote from both parents, beside the plain cross of their own maxims. The child's gate re-runs in your browser, maxim by maxim.
  6. Re-run it yourself. Everything the measurement reads is committed. On any machine with Node 20 or later: 
    git clone https://github.com/sjgant80-hub/bred-minds
cd bred-minds
npm test
node tools/measure-1.mjs --check
    The last line rebuilds the receipt from the committed replies and says whether it matches byte for byte. No model is asked anything.
The words this page uses, in plain terms
Card
A small pattern-model of one mind: twelve one-sentence maxims drawn from the author's own book, plus two 60-word samples of the author's voice.
Maxim
One sentence stating the main claim of one passage of the book, written by the local model and checked by the gate.
The gate
A fixed rule that keeps a maxim only if it has 6 to 40 words, shares at least two content words with its own passage (a content word is 4 or more letters and not a common word like "which"), and names no blocked word. It checks that a maxim traces to its passage, not that it is wise.
Blocked words
The six thinkers' names, their best-known books and the schools named after them (listed under The cards). An answer that names one could win just by naming, so it is asked again, and if it still names one it counts as a miss.
Card answer
An answer to a question about how to live, written by the local model from one card alone.
Sham card, sham answer
The control. A sham card holds twelve maxims drawn at random from all six cards, under one mind's label. A sham answer is written from it. If sham answers were "recognised" as their label as often as card answers, the cards would carry nothing.
Base answer
An answer the local model writes from no card at all: its own voice, the other control.
Cold judge
A fresh Claude Opus 5.5 session that sees only a batch of shuffled answers, never a card, and gives each answer a number for each thinker and for none.
Trace model
A word-count model (naive Bayes) fitted on the six books. It has no language model inside it: it only knows which words each author used, and how often.
FIT and TEST
Passages 8 and 9 of every ten are TEST: held back, and never read by anything except the trace model's test. The rest are FIT.
Temperature 0
The local model's randomness turned off, so the same passage always gives the same maxim and anyone can repeat it. The answers use temperature 0.7, with a fixed seed for each.
Macro-averaged accuracy
The share of each author's TEST passages the trace model got right, averaged over the six, so the author with the longest book does not dominate.
Wilson 95% bound
The range a rate very probably lies in, given how few cases it was measured on. A claim "above 1 in 6" holds only if the whole range is above 1 in 6.
Bootstrap lower bound
The same idea for a difference: the cases are resampled 2,000 times, and the claim holds only if the low end (the 2.5th percentile) of the difference is past the bar.
Sealed
Written down and committed before the code that measures it existed. The measurement refuses to run if the sealed file has changed.
Receipt; byte for byte on GitHub's runner
The receipt is the file of results. On every change, GitHub's own computers rebuild it from the committed records and fail the build if a single character differs. Nobody has to trust our laptop.
Child, naive cross, control (organ 2)
A child is a new card the local model writes from two parent cards. A naive cross is the plain mix: six of each parent's own maxims. The control is each parent's answers alone, showing how often a partner gets named beside it for free.

The cards

Each card was grown from one author's own words. The local model (qwen2.5:7b, on the laptop, temperature 0) read 24 passages drawn from the book and stated each passage's main claim in one plain sentence. A gate kept a sentence only if it had 6 to 40 words, shared at least two content words with its passage, and named no author, book or school of thought. The first twelve kept are the card's maxims. The first 60 words of the passages behind the first two are its voice.

Loading the cards…

The sham cards

A sham card is the control. It holds twelve maxims drawn at random from all six cards pooled together, and the voice of two cards, and it is labelled with one mind. If a judge "recognises" sham answers as that mind about as often as real ones, the real cards carry nothing. The receipt checks that real cards beat shams.

The blocked words, and why

These are fixed in the seal. A maxim that names one is dropped by the gate. An answer that names one is asked once more with a new seed. If it still names one, it is kept, marked, and counted as a miss for its card, so no answer can be "recognised" just by naming its thinker. Matching is whole words, any case.

The gate at work: one kept, one dropped, from the real run

Blind test

This is the test the judge took, one answer at a time. Each answer was written by the local model to one of 20 questions about how to live, from one card, from a sham card, or from no card. You do not see which. Guess.

The 200 answers are being written by the local model; this test opens when they are committed.

The trace model

The judge is a large language model, and it knows these six thinkers well. The trace model is the other check: it has no language model inside it. It counts words. It was fitted on 8 of every 10 passages of the six old books, and it attributes a text to the author whose word counts make that text most likely. If it recognises a card's answers too, the pattern carried into the words themselves.

Breeding

Organ 2 breeds the cards. For every pair of the six minds, the local model reads both parent cards and writes sixteen new maxims for a single pattern of thought that holds both. A gate keeps a new maxim only if:

  • it is 6 to 40 words;
  • it is written wholly in Latin script (organ 1 taught this rule: one of its maxims ended in Chinese);
  • it names no thinker, book or school;
  • it shares at least two content words with the parents' maxims;
  • it is not a near-copy of any one parent maxim.

The first twelve kept are the child. Beside every child sits its control, the naive cross: six of each parent's own maxims, alternating, with the same voice. If breeding is worth anything, the child must carry both parents at least as well as that plain mix does, in new words.

How it works

  1. Six books. Six Project Gutenberg files, byte for byte, each read only from the heading where the author's own words begin to where they end, so no editor's introduction is in it.
  2. Passages. Paragraphs joined into passages of 120 to 400 words, numbered in book order. Passages 8 and 9 of every ten are TEST: nothing reads them but the trace model's test.
  3. Maxims. For each mind, 24 FIT passages drawn by a seeded shuffle. The local model states each one's main claim in one sentence, at temperature 0, so the same passage always gives the same sentence.
  4. The gate. A sentence is kept only if it has 6 to 40 words, shares at least two content words with its own passage, and names no author, book or school.
  5. The card. The first twelve kept, and two 60-word samples of the author's voice. A card's id is the SHA-256 of its canonical JSON, so one changed word is a different card.
  6. 200 answers. The local model answers 20 questions about how to live from each card (120), with no card (20), and from six sham cards (60). Any answer that names a thinker is asked once more; if it still names one, it counts as a miss.
  7. Two checks, then the receipt. The cold judge (Claude Opus 5.5, a fresh agent per batch that sees only the 50 answers in front of it) gives each answer a number for each of the six thinkers and for none. The trace model attributes each answer too. The measurement reads only committed files and writes the receipt.

Blueprint

Built organ by organ. Each kernel is pure and deterministic: nonsense in gives an empty result, never a crash. Each one is under a mutation gate: the gate changes the code in every way it can, and the tests must catch every change.

The tools and the records

  • claims/organ-1.json: the seal. Every prompt word for word, every seed, every threshold, the 20 questions, the blocked words, the seven claims and what was expected. Committed before any model was asked anything.
  • tools/stock.mjs: builds every prompt from the seal's own words (a test checks them word for word) and draws each mind's passages.
  • tools/ollama.mjs: the local model, pinned by its digest; every reply is kept with the hash of the prompt that asked it.
  • tools/grow-maxims.mjs → data/local/maxims.json; tools/cards.mjs → data/cards.json (rebuilds byte for byte).
  • tools/write.mjs → data/local/perspectives.json: the 200 answers with their seeds.
  • tools/judge.mjs → data/judge/: the four shuffled batches, the order kept apart, and the judge's replies.
  • Organ 2: claims/organ-2.json (its seal, committed before its code); tools/stock2.mjs (the breeding prompt and the judge head, tested word for word against that seal); tools/breed.mjs → data/local/children.json and data/children.json; tools/write2.mjs → data/local/perspectives-2.json; tools/judge2.mjs → data/judge2/ (eight batches of 45); tools/measure-2.mjs → receipts/organ-2.json. Before any model was asked, the whole chain was dry-run on fake data in a scratch copy, and the measurement read the planted numbers back exactly.
  • tools/measure-1.mjs → receipts/organ-1.json. It refuses to run if the seal has changed since it was committed.
  • On every push, GitHub's own runner runs every test, the mutation gate on every kernel, and rebuilds the receipt from the committed replies.

For your business

Who it is for: anyone who builds AI that speaks in the manner of a source. A tutor in the manner of a classic author. An assistant that follows your firm's own written methods. A brand voice. A model of a retiring expert's written reasoning, with their agreement.

What it gives you: a pattern grown from the source's own words, with every line traced to the passage it came from, and a blind test against shams before anyone relies on it. When the pattern did not carry, the receipt says so, so you ship only what held.

Rolling it out

  1. Choose the source. Texts you own, or public domain. They stay on your machine.
  2. Seal what counts. Write down, before anything runs, what "the pattern carried" means for you: the questions, the shams, the bar to beat.
  3. Grow the cards on your own laptop with a local model. No cloud account is needed for this step.
  4. Run the blind test: a judge that never sees the cards, a sham control, and the trace model.
  5. Ship what held, and re-run whenever the source or the model changes. The receipt rebuilds from the committed records, so an auditor can check it without trusting you.

Risks, answered straight

For the board

White paper

Breeding stock: growing pattern-models of thought from public-domain text, and testing them blind

The question. Can a small card, twelve maxims drawn from an author's own words and two short samples of the author's voice, carry a pattern of thought that others recognise? If it can, such cards can be checked, compared and later bred. If it cannot, any persona built this way is decoration.

Stock. Six public-domain books from Project Gutenberg: Marcus Aurelius's Meditations (Meric Casaubon's translation, 1634), Michel de Montaigne's Essays (Charles Cotton's translation), Ralph Waldo Emerson's Essays, First Series, William James's Pragmatism, Friedrich Nietzsche's Beyond Good and Evil (Helen Zimmern's translation) and Henry David Thoreau's Walden with Civil Disobedience. Each is read only from where the author's own words begin, cut into passages of 120 to 400 words and split by a fixed rule: two of every ten passages are held out for testing.

Growth. A 7-billion-parameter model running locally states the main claim of each of 24 drawn passages in one sentence, at temperature 0. A gate keeps a sentence only if it is 6 to 40 words, shares two or more content words with its passage, and names no thinker, book or school. Twelve kept sentences and two 60-word voice samples make the card.

The test. The same local model answers twenty questions about how to live from each card, from no card, and from sham cards that pool maxims from all six cards under one mind's label. A cold judge, which sees only batches of fifty shuffled answers, gives every answer a number for each thinker and for none. A word-count model fitted on the books, with no language model inside it, attributes every answer too. Seven claims, with their thresholds, were committed before any of this code existed.

What it does not claim. These are models of thought-patterns. They are not the people, not resurrections and not conscious. Recognition by a judge that knows these thinkers well shows that a pattern carried far enough to be named; it does not show that a card says what the author would have said.

Breeding (organ 2). For each of the 15 pairs of cards, the local model writes sixteen new maxims for one pattern that holds both. A stricter gate keeps a maxim only if it is in Latin script, traces to the parents' words, and copies no single parent maxim. The child's answers are judged in the same blind batches as two controls: a naive cross of six of each parent's own maxims, and each parent's answers alone. Each parent's answers alone measure how often a partner gets named beside it for free. Every recognition claim is barred against those controls, not against chance. That is the lesson organ 1's trace model taught.

Straight answers

Is this the real Marcus Aurelius?

No. It is a card of twelve sentences a small model drew from a 1634 translation of his notebooks, checked against the passages they came from. It is a model of a pattern of thought, not the man, and it is not conscious.

Why these six?

Their books are public domain in the UK and the US, their patterns of thought are distinct, and a judge knows them well enough to be a hard test. Carl Jung was left out: his writing is in UK copyright until 2031. William James carries psychology instead.

Why a sham card?

A judge that knows these thinkers might guess "Marcus" for anything stoical-sounding. A sham card is labelled with a mind but holds maxims from all six. If sham answers were "recognised" as often as real ones, the real cards would carry nothing. The receipt checks that the real cards beat the shams by more than chance.

Are the maxims faithful to what the author meant?

The gate cannot tell you that, and the page does not claim it. The gate checks only that each maxim traces to its own passage: it shares the passage's words, keeps to one sentence, and names no thinker. It does not check meaning. Two things let a person check meaning:

  • Every maxim on every card opens to the passage it came from, so a reader can judge it against the book in seconds.
  • Every sentence the gate dropped is listed with its reason.

Of the 144 sentences the local model wrote, 126 passed the gate and 72 are on the cards. Some read as summaries ("The main claim is that…"), and one ends in Chinese. They are shown as they are. What the blind test adds is evidence that a pattern carried, not that every maxim is right.

Could the judge just be biased, or guessing from famous ideas?

It knows these thinkers well, so it is tested against three controls in the same blind batches:

  • Sham answers, from cards that mix all six minds under one label. It named the label 5 times in 60, against 114 times in 120 for real cards.
  • Base answers, from no card. It gave "none" 80.7 points on average, against 13.4 for card answers.
  • The trace model, which has no language model inside it at all.

A judge guessing from fame would score the shams as high as the cards. It did not. This is one run, so its record is this receipt, not a history. You can swap in any judge you trust, and the receipt names which judge was used.

Does the local model's own modern voice skew the results?

It writes modern English, and that is measured, not assumed. The base answers (no card) show its own voice: the judge read them as "none of the six". The trace model is where the modern voice shows most: it leans toward Emerson and James for any modern-English advice. That is shown in full under Results. Why it leans is a guess, not a measured cause. The next organ measures against controls that carry the same lean, so the lean cancels out.

What if a source text has errors, or is in another language?

The texts are used exactly as published, byte for byte, with their fingerprints recorded. An error in a source passes into its passage, and the passage is shown beside every maxim, so it is visible. The method works for any language your local model writes well. The trace model as built counts English words only (the letters a to z), so a source in another language needs its own word rule, sealed before it is used.

How would an editor check a persona before it ships?
  1. Read each maxim beside its passage, and strike any that misstate the book.
  2. Read the dropped list.
  3. Run the blind test against shams on questions your readers actually ask.
  4. Ship only if the receipt says held.

When an author's card fails, the receipt says so, claim by claim, and the card does not ship. A wrong persona is caught by a failed claim, not by a complaint.

What exactly did the judge see?

Four fresh Claude Opus 5.5 sessions, one per batch of 50 shuffled answers. Each read its batch file and wrote its reply: two tool uses each, by the harness's own record. Each session also carried the standing instructions every subagent on this machine is given. Those are the operator's own working rules: no card, no answer key and no order of the answers. Which answer sits where is kept in data/judge/order.json, which no judge read. The token counts are in data/judge/usage.json, and the cost case pays for all of them.

Why a trace model as well as the judge?

Because the judge is itself a language model that has read about these thinkers. The trace model has read nothing but the six old books and counts words. If it also recognises a card's answers, the pattern reached the words, not just the ideas a judge associates with a name. In organ 1 it also showed a lean, found after the receipt and shown under Results: it sends most modern-English advice to Emerson or James, whoever wrote it. So its count against chance says less than it seems, and the next organ measures the trace model against the controls, not against chance.

Can I trust numbers I cannot re-run?

You do not have to. Clone the repository and run node tools/measure-1.mjs --check: it rebuilds the receipt from the committed replies, byte for byte, without asking any model anything. GitHub's runner does the same on every push.

Can I use my own texts?

Yes. Put the files in data/texts/, name them in data/sources.json with their hashes and where the author's own words begin and end, write and commit your own seal, then run the tools in order.

What happens to an answer that names the thinker?

It is asked once more with a different seed. If it still names a thinker, book or school, it is kept, marked, and counted as a miss for the card, so a giveaway can never count as recognition.
